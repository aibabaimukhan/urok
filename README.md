# GitHub Pages
1. Создайте репозиторий, загрузите все файлы из папки site в корень.
2. Settings → Pages → Deploy from branch → main / root.
3. Вставьте URL Apps Script в core.js (const API=...). Код сервера — Code.gs.
4. Открывайте https://<user>.github.io/<repo>/ (index.html — страница преподавателя).
Страницы: index.html (преподаватель, QR, графики), learn.html (материал), tasks.html (практика), reflect.html (рефлексия).

Свои QR-картинки: положите рядом с index.html файлы qr-lecture.png, qr-task.png, qr-reflect.png — они подставятся автоматически (иначе QR генерируется сам).
